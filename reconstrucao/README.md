# AIGAR — Reconstrução

Área dedicada à reconstrução, organização e evolução do AIGAR.

## Objetivo

Preservar e reconstruir progressivamente a arquitetura, contexto, memória, lógica e componentes do AIGAR a partir dos materiais de referência e do código verificável.

## Regra de trabalho

- preservar o que já estiver validado;
- separar contexto, hipótese e implementação;
- verificar o código antes de afirmar capacidades;
- registrar decisões importantes;
- trabalhar de forma incremental.

## Estrutura inicial

Esta pasta será expandida conforme a reconstrução avançar.
